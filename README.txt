SICOM SARL — Site vitrine HTML/CSS/JavaScript
================================================

Fichiers :
- index.html : contenu du site
- style.css  : design responsive (ordinateur, tablette, mobile)
- script.js  : menu mobile, année automatique et formulaire e-mail

Pour ouvrir :
1. Décompressez le ZIP.
2. Ouvrez index.html dans votre navigateur.

Personnalisation importante avant publication :
- Remplacer l’adresse e-mail contact@sicom-sarl.com si elle n’est pas la bonne.
- Ajouter le vrai numéro de téléphone et l’adresse de SICOM SARL.
- Vérifier les activités et familles de produits réellement proposées.
- Le formulaire prépare un e-mail dans l’application de messagerie du visiteur ; il ne stocke ni n’envoie les données sur un serveur.
- Les photos sont chargées depuis Unsplash et les polices depuis Google Fonts : une connexion Internet est nécessaire pour ces éléments.
- Pour recevoir des messages directement depuis le site, connecter le formulaire à un backend ou à un service de formulaire.

Le site est livré comme site statique HTML/CSS/JS, sans installation ni framework requis.
